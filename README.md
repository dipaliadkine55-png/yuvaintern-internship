# TechNova Responsive Landing Page

## Week 1 Task – Responsive Landing Page Development

TechNova is a responsive landing page developed using HTML5, CSS3, and vanilla JavaScript.

The project demonstrates responsive design, semantic HTML, CSS Flexbox/Grid, media queries, accessibility, and JavaScript-based mobile navigation.

---

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* CSS Flexbox
* CSS Grid
* CSS Media Queries

No external frameworks or libraries are required.

## Features

### Responsive Layout

The website adapts to:

* Desktop
* Laptop
* Tablet
* Mobile phones

### Responsive Navigation

On desktop devices, the navigation links are displayed horizontally.

On smaller screens, the links are hidden and a hamburger menu is displayed.

### Mobile Menu

The mobile navigation supports:

* Click to open
* Click to close
* Navigation link selection
* Escape key to close
* `aria-expanded` accessibility state

### Hero Section

The hero section contains:

* Main heading
* Description
* Call-to-action buttons
* Responsive dashboard illustration

### Features Section

Three feature cards are included:

1. Fast Performance
2. Responsive Design
3. Modern Technology

### About Section

The about section explains the purpose of the fictional TechNova company.

### Call-to-Action

A CTA section encourages users to contact the company.

### Footer

The footer contains:

* Brand information
* Quick links
* Contact information
* Dynamic copyright year

## Responsive Behavior

### Desktop

The hero section uses a two-column layout.

The features are displayed in three columns.

The navigation links are visible.

### Tablet

The layout begins adapting to smaller widths.

Feature cards may use two columns.

### Mobile

The hero changes to a single-column layout.

Feature cards are stacked vertically.

The desktop navigation is replaced by a hamburger menu.

Buttons expand to use the available width on very small screens.
